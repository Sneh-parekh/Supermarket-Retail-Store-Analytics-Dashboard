# 📊 Supermarket Retail Store Analytics Dashboard

## 📌 Project Overview

This project is an interactive Excel-based analytics dashboard developed for a supermarket retail business to analyze sales performance, employee productivity, and receivables management. The dashboard was built using Microsoft Excel with Pivot Tables, Pivot Charts, KPI Cards, Slicers, and dashboard navigation.

The project focuses on transforming raw retail data into meaningful business insights through professional and visually interactive dashboards.

---

# 📂 Dashboard Pages

## 🏠 1. Dashboard Overview

The Overview Dashboard provides a high-level summary of overall retail business performance.

### Key Metrics

* Total Net Sales
* Total Profit
* Total Orders
* Target Achievement %

### Visuals Included

* Monthly Sales Trend
* Region-wise Sales Analysis
* Category-wise Sales Distribution
* Payment Mode Analysis

### Features

* Interactive slicers
* Dynamic KPI cards
* Page navigation buttons
* Professional dashboard layout

## 👥 2. Employee Performance Dashboard

The Employee Dashboard analyzes workforce productivity and performance.

### Key Metrics

* Total Executives
* Average Attendance %
* Total Target Sales
* Target Achievement %

### Visuals Included

* Top Performing Executives
* Bottom Performing Executives
* Manager-wise Sales Analysis
* Attendance Analysis
* Top Executive Card
* Top Manager Card

### Business Insights

* Employee performance comparison
* Team performance tracking
* Attendance monitoring
* Executive target achievement analysis

## 💰 3. Receivables & Collections Dashboard

This dashboard focuses on payment collections and pending receivables analysis.

### Key Metrics

* Total Pending Amount
* Collection Rate %

### Visuals Included

* Region-wise Pending Amount

* Average Aging Analysis

### Business Insights

* Payment delay analysis
* Receivables risk monitoring
* Customer due tracking
* Regional collection performance

# 🗂️ Dataset Information

The project uses multiple datasets linked together for analysis.

## Sheets Used

### Sales_Data

Contains order-level retail sales transactions.

### Employee_Master

Contains employee and manager information.

### Monthly_Targets

Contains monthly sales targets for executives.

### Attendance

Contains employee attendance records.

### Collections

Contains pending payment and receivable details.
